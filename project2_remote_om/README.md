# Project 2: i.MX6ULL Remote O&M

This project is the code area for an i.MX6ULL remote operation and
maintenance system.

The code is split by runtime side:

- `board/`: programs and scripts that run on the embedded Linux board
- `server/`: PC-side management server, OTA files, and test logs
- `common/`: protocol and shared design notes
- `docs/`: build, deployment, and test documentation
- `release/`: staged release output generated by packaging scripts

Initial development target:

1. Build a PC TCP management server.
2. Build a board-side `device_agent`.
3. Complete register, heartbeat, status report, command, and ACK flow.
4. Add logs, service management, OTA, and power management step by step.

Current stage contains the minimum TCP flow plus heartbeat and status report:

```text
device_agent -> register -> manage_server
device_agent <- ack      <- manage_server
device_agent -> heartbeat -> manage_server
device_agent <- ack       <- manage_server
device_agent -> status_report -> manage_server
device_agent <- ack           <- manage_server
device_agent <- command       <- manage_server
device_agent -> ack           -> manage_server
device_agent -> log_line      -> manage_server
```
