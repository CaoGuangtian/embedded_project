# PC Management Server

This directory contains the PC-side management server and test assets.

Planned responsibilities:

- Accept board connections
- Track online device state
- Receive register, heartbeat, and status messages
- Send remote commands
- Receive ACK messages
- Serve or describe OTA upgrade packages

Subdirectories:

- `ota/`: OTA metadata and test upgrade packages
- `logs/`: local server-side test logs
